## तुलना के मापदंड

| मापदंड | क्या मापता है |
| --- | --- |
| कार्य सफलता, pass^1 | आवश्यक अंतिम डेटाबेस स्थिति और सूचना संचार |
| कवरेज और विफलताएँ | स्कोर किए/नियोजित प्रयास, सामान्य समाप्ति और बिना स्कोर की अनुमान त्रुटियाँ |
| विलंब, p50 / p95 | एजेंट LLM और ASR निष्पादन; TTS के पहले ऑडियो तक समय |
| वॉइस उत्तर विलंब | कॉलर की बात समाप्त होने से एजेंट के पहले ऑडियो तक; मानकीकृत सारांश शेष |
| टूल त्रुटि दर | विफल या अस्वीकृत एजेंट कॉल / कुल किए गए प्रयास |
| समापन समय | सिम्युलेटेड कॉल समय और मापा वास्तविक समय अलग-अलग |
| अधिकतम मेमोरी | मापन क्षेत्र सहित नेटिव प्रक्रिया की भौतिक मेमोरी |
| API लागत | प्रति प्रयास और सफल प्रयास USD; विफल प्रयास शामिल |

एक ही कार्य, सीड, कॉल सीमाएँ, ध्वनिक स्थितियाँ और कॉलर/जज सेटिंग की तुलना करें। स्थानीय LLM की तुलना में स्पीच स्टैक स्थिर रखें। ऑडियो-नेटिव और प्रबंधित एजेंटों को पूरा स्टैक बताना चाहिए। घटकों का समय और शुरू से अंत तक वॉइस उत्तर विलंब अलग माप हैं।

## दर्ज स्थानीय निदान

| एजेंट | स्कोर किए / नियोजित | Pass^1 | टूल त्रुटियाँ | LLM p50 / p95 | TTS पहला ऑडियो p50 / p95 | API लागत / प्रयास |
| --- | --- | --- | --- | --- | --- | --- |
| Gemma 4 12B IT, INT4 | 1/1 | 0/1 | 1/6 | 7.00 / 11.13 s | 1.22 / 1.70 s | $0 |

एयरलाइन कार्य 12, एक प्रयास, सीड 70, v2; अधिकतम **600 सिम्युलेटेड सेकंड / 1,200 वास्तविक सेकंड**। कॉल **312.9 सिम्युलेटेड सेकंड / 554.4 मापे वास्तविक सेकंड** में सामान्य रूप से समाप्त हुई। हार्डवेयर: Apple M5 Pro, 48 GB, साझा वर्कस्टेशन। यह एक विकास प्रयास है; समान स्थितियों वाली कई मॉडलों की रैंकिंग अभी शेष है। [डेटा और मापन परिभाषाएँ](docs/results/gemma4-12b-local-v2-airline.json).

## स्थानीय रूप से चलाएँ

Python **3.12/3.13**, Apple Silicon, **macOS 15+**। स्थानीय सेवा शुरू करने, कॉलर/जज को सत्यापित करने और कार्य चलाने के लिए [सेटअप](docs/runtime-setup.md) और [v2 निष्पादन](docs/local-v2.md) देखें।

```bash
uv sync --frozen --extra dev
uv run --frozen tau-voice verify
```

`--num-tasks`, `--trials`, `--max-seconds` और `--wall-timeout` से निष्पादन सीमित करें। क्लाउड एडाप्टर और USD खर्च सीमा **अभी लागू नहीं किए गए हैं**। वर्तमान अनुमान स्थानीय है और क्लाउड API कुंजी नहीं चाहिए।

जाँच: `make test` · `make lint` · `make verify`.
