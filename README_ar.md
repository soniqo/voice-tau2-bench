تدير [Soniqo](https://github.com/soniqo) هذا المعيار لقياس قدرة الوكلاء الصوتيين على إكمال المهام بالحوار المنطوق والأدوات. تضم المجموعة الإنجليزية الثابتة **278 مهمة**: الطيران **50**، التجزئة **114**، الاتصالات **114**.

[الإعداد](docs/runtime-setup.md) · [التقييم](docs/evaluation.md) · [مقارنة النماذج والحدود](docs/model-comparison.md)

## النماذج والأنظمة

| الوكيل أو النظام | الدعم الحالي |
| --- | --- |
| Gemma 4 12B IT, INT4 | ملف تعريف محلي v2 مختبر |
| Gemma 4 E4B IT, INT4 | مدعوم في بيئة التشغيل المحلية؛ المقارنة المتكافئة باستخدام v2 لم تُنفذ بعد |
| Amazon Nova 2.5 Sonic | تم التحقق من المعالجة الصوتية المباشرة؛ Retail pass^1 **1/1** (تجربة تطوير واحدة v6، بحد 420 ثانية؛ [السجل](docs/results/nova25-v6-retail-development.json)) |
| OpenAI GPT-Live + وكيل خلفي محدد بالاسم | [تم اختبار المحول التجريبي دون اتصال؛ التحقق مع الخدمة الفعلية لم يُنفذ بعد](docs/providers.md) |
| OpenAI Realtime | [تم اختبار المحول التجريبي دون اتصال؛ التحقق مع الخدمة الفعلية لم يُنفذ بعد](docs/providers.md) |
| Gemini Live | [تم اختبار المحول التجريبي دون اتصال؛ التحقق مع الخدمة الفعلية لم يُنفذ بعد](docs/providers.md) |
| ElevenLabs Agents | [تم اختبار المحول التجريبي دون اتصال؛ التحقق مع الخدمة الفعلية لم يُنفذ بعد](docs/providers.md) |

تستخدم المنظومة المحلية [speech-swift](https://github.com/soniqo/speech-swift): Whisper Large-v3 الكامل بدقة FP16، أوزان VoxCPM2 الرئيسية FP16 وAudioVAE بدقة FP32، وSilero VAD، وGemma E4B للمتصل ومساعدات الاستماع والمقيّم. يتوفر لـ Nova 2.5 Sonic [مشغّل صوت أصلي](docs/nova.md) اختياري؛ ويبقى المتصل والمقيّم محليين.

## مقاييس المقارنة

| المقياس | ما يقيسه |
| --- | --- |
| نجاح المهمة، pass^1 | الحالة النهائية المطلوبة لقاعدة البيانات والتواصل |
| التغطية والإخفاقات | المحاولات المقيّمة/المخططة، النهايات الطبيعية، وأخطاء الاستدلال غير المقيّمة |
| زمن الاستجابة، p50 / p95 | تنفيذ LLM وASR للوكيل؛ زمن TTS حتى أول مقطع صوتي |
| تأخير الاستجابة الصوتية | من نهاية كلام المتصل إلى أول صوت للوكيل؛ التجميع الموحد لم يُنفذ بعد |
| معدل أخطاء الأدوات | استدعاءات الوكيل الفاشلة أو المرفوضة / محاولات الاستدعاء |
| زمن الإكمال | زمن المكالمة المحاكى والزمن الفعلي المقاس، كل على حدة |
| ذروة الذاكرة | استهلاك الذاكرة الفعلية للعملية الأصلية مع نطاق القياس |

قارن المهام والبذور والحدود والظروف الصوتية وإعدادات المتصل/المقيّم نفسها. ثبّت منظومة الصوت عند مقارنة نماذج LLM المحلية. يجب تحديد المنظومة الكاملة للوكلاء الصوتيين الأصليين والخدمات المُدارة. أزمنة المكونات منفصلة عن تأخير الاستجابة الصوتية من البداية إلى النهاية.

## نتائج تجارب التطوير المسجلة

تجربة تطوير واحدة في كل صف. تختلف المهام وإعدادات الوقت؛ لم يُنجز بعد ترتيب النماذج بظروف متكافئة.

| الوكيل | الإعداد / المهمة | المقيّمة / المخططة | Pass^1 | أخطاء الأدوات | الوقت الفعلي |
| --- | --- | --- | --- | --- | --- |
| Gemma 4 12B IT, INT4 | v2 · الطيران 12 | 1/1 | 0/1 | 1/6 | 554.4 s |
| Amazon Nova 2.5 Sonic | v6 · التجزئة 0 | 1/1 | **1/1** | **0/5** | **296.3 s** |

مهمة الطيران 12، محاولة واحدة، البذرة 70، v2؛ بحد أقصى **600 ثانية محاكاة / 1,200 ثانية فعلية**. انتهت المكالمة طبيعيًا بعد **312.9 ثانية محاكاة / 554.4 ثانية فعلية مقاسة**. العتاد: Apple M5 Pro، ذاكرة 48 GB، محطة عمل مشتركة. هذه محاولة تطوير واحدة؛ ترتيب عدة نماذج بظروف متكافئة لم يُنجز بعد. [البيانات وتعريفات القياس](docs/results/gemma4-12b-local-v2-airline.json).

Gemma LLM p50 / p95: **7.00 / 11.13 s**; TTS p50 / p95: **1.22 / 1.70 s**.

Nova: تجربة واحدة، البذرة 70، ظروف صوتية control، **حد 420 ثانية فعلية**. تم استبدال السلعتين المطلوبتين؛ تطابقت الإجراءات المرجعية **5/5** والحالة النهائية لقاعدة البيانات. انتهت المكالمة طبيعيًا بعد **259.0 ثانية صوتية / 296.3 ثانية فعلية**. [السجل والحدود](docs/results/nova25-v6-retail-development.json).

## التشغيل محليًا

Python **3.12/3.13**، Apple Silicon، **macOS 15+**. اتبع [الإعداد](docs/runtime-setup.md) و[تشغيل v2](docs/local-v2.md) لبدء الخدمة المحلية والتحقق من المتصل/المقيّم وتنفيذ المهام.

```bash
uv run --frozen --extra dev python scripts/run_local_voice.py \
  --output data/simulations/first-local-run
```

يبني هذا الأمر بيئة التشغيل الأصلية المثبتة، وينزّل النماذج، ويعاير المتصل والمقيّم، ثم يجري اختبارًا صوتيًا مضبوطًا. لا ينتج عنه تقييم لمعيار المجالات. استخدم مجلد إخراج جديدًا. [الإعداد وتشغيل المهام](docs/runtime-setup.md#one-command-local-run).

حدّد التنفيذ باستخدام `--num-tasks` و`--trials` و`--max-seconds` و`--wall-timeout`. يبقى التشغيل الافتراضي محليًا. مشغلات اختيارية: [Nova](docs/nova.md) · [OpenAI وGemini وElevenLabs](docs/providers.md).

الفحوص: `make test` · `make lint` · `make verify`.
