# voice-tau2-bench

[English](README.md) · [简体中文](README_zh.md) · [日本語](README_ja.md) · [한국어](README_ko.md) · [Español](README_es.md) · [Deutsch](README_de.md) · [Français](README_fr.md) · [हिन्दी](README_hi.md) · [Português](README_pt.md) · [Русский](README_ru.md) · [العربية](README_ar.md) · [ไทย](README_th.md) · [Türkçe](README_tr.md) · [Tiếng Việt](README_vi.md)

[Soniqo](https://github.com/soniqo) поддерживает этот бенчмарк, чтобы измерять, выполняют ли голосовые агенты задачи через устный диалог и инструменты. Зафиксированный английский набор содержит **278 задач**: авиаперевозки **50**, торговля **114**, связь **114**.

[Настройка](docs/runtime-setup.md) · [Оценка](docs/evaluation.md) · [Сравнение моделей и ограничения](docs/model-comparison.md)

## Модели и системы

| Агент или система | Текущая поддержка |
| --- | --- |
| Gemma 4 12B IT, INT4 | Проверенный локальный профиль v2 |
| Gemma 4 E4B IT, INT4 | Локальная среда поддерживает; сопоставимый прогон v2 ещё не выполнен |
| Amazon Nova 2.5 Sonic | Нативное аудио проверено; Retail pass^1 **1/1** (один тест разработки v6, лимит 420 с; [результат](docs/results/nova25-v6-retail-development.json)) |
| OpenAI GPT-Live + указанный серверный агент | Нужен адаптер |
| OpenAI Realtime | Нужен адаптер |
| Gemini Live | Нужен адаптер |
| ElevenLabs Agents | Нужен адаптер |

Локальный стек использует [speech-swift](https://github.com/soniqo/speech-swift): полный Whisper Large-v3 FP16, основные веса VoxCPM2 FP16 / AudioVAE FP32, Silero VAD и Gemma E4B для звонящего, помощников прослушивания и оценщика. Для Nova 2.5 Sonic доступен необязательный [нативный аудиозапуск](docs/nova.md); звонящий и оценщик остаются локальными.

## Метрики сравнения

| Метрика | Что измеряет |
| --- | --- |
| Успех задачи, pass^1 | Требуемое конечное состояние базы и передачу информации |
| Покрытие и сбои | Оценённые/запланированные попытки, нормальные завершения и неоценённые ошибки инференса |
| Задержка, p50 / p95 | Выполнение LLM и ASR агента; время TTS до первого аудиофрагмента |
| Задержка голосового ответа | От конца речи звонящего до первого аудио агента; стандартная сводка ещё не реализована |
| Доля ошибок инструментов | Неудачные или отклонённые вызовы агента / все попытки вызова |
| Время завершения | Моделируемую длительность звонка и измеренное реальное время отдельно |
| Пиковая память | Физическую память нативного процесса с указанием области измерения |
| Стоимость API | USD за попытку и успешную попытку; учитывать неудачные попытки |

Сравнивайте одинаковые задачи, seed, ограничения, акустику и настройки звонящего/оценщика. При сравнении локальных LLM сохраняйте речевой стек. Агенты с нативным аудио и управляемые сервисы должны указывать полный стек. Время отдельных компонентов отличается от сквозной задержки голосового ответа.

## Записанные результаты отладочных прогонов

В каждой строке один отладочный прогон. Задачи и настройки времени различаются; сопоставимый рейтинг моделей ещё не готов. Стоимость указана для завершённых звонков.

| Агент | Условие / задача | Оценено / запланировано | Pass^1 | Ошибки инструментов | Реальное время | API USD за звонок |
| --- | --- | --- | --- | --- | --- | --- |
| Gemma 4 12B IT, INT4 | v2 · Авиация 12 | 1/1 | 0/1 | 1/6 | 554.4 s | $0 |
| Amazon Nova 2.5 Sonic | v6 · Розница 0 | 1/1 | **1/1** | **0/5** | **296.3 s** | **$0.0315** |

Авиационная задача 12, одна попытка, seed 70, v2; максимум **600 моделируемых секунд / 1 200 реальных секунд**. Звонок завершился нормально через **312,9 моделируемых секунд / 554,4 измеренных реальных секунд**. Оборудование: Apple M5 Pro, 48 ГБ, общий компьютер. Это один отладочный прогон; сопоставимый рейтинг нескольких моделей ещё не готов. [Данные и определения метрик](docs/results/gemma4-12b-local-v2-airline.json).

Gemma LLM p50 / p95: **7.00 / 11.13 s**; TTS p50 / p95: **1.22 / 1.70 s**.

Nova: одна попытка, seed 70, акустика control, **лимит 420 с реального времени**. Оба запрошенных товара обменены; совпали **5/5** эталонных действий и конечное состояние базы данных. Звонок завершился нормально через **259,0 с аудио / 296,3 с реального времени**. При учёте общих расходов нужно включать и прерванные попытки. [Результат и ограничения](docs/results/nova25-v6-retail-development.json).

## Локальный запуск

Python **3.12/3.13**, Apple Silicon, **macOS 15+**. Следуйте [настройке](docs/runtime-setup.md) и [запуску v2](docs/local-v2.md), чтобы запустить локальный сервис, проверить звонящего/оценщика и выполнить задачи.

```bash
uv run --frozen --extra dev python scripts/run_local_voice.py \
  --output data/simulations/first-local-run
```

Эта команда собирает закреплённую нативную среду, загружает модели, калибрует собеседника и оценщика и запускает контролируемую голосовую проверку. Она не создаёт оценку доменного бенчмарка. Используйте новый каталог вывода. [Настройка и запуск задач](docs/runtime-setup.md#one-command-local-run).

Ограничивайте запуск параметрами `--num-tasks`, `--trials`, `--max-seconds` и `--wall-timeout`. Запуск по умолчанию остаётся локальным. Для [Nova](docs/nova.md) нужен явно заданный профиль AWS. Есть постоянный учёт бюджета и порог потребления, но это не установленный провайдером жёсткий денежный лимит.

Проверки: `make test` · `make lint` · `make verify`.
