[Soniqo](https://github.com/soniqo) ดูแลเบนช์มาร์กนี้เพื่อวัดว่าเอเจนต์เสียงทำงานสำเร็จผ่านการสนทนาและการใช้เครื่องมือได้หรือไม่ ชุดภาษาอังกฤษที่ตรึงไว้มี **278 งาน**: สายการบิน **50** ค้าปลีก **114** โทรคมนาคม **114**

[การตั้งค่า](docs/runtime-setup.md) · [การให้คะแนน](docs/evaluation.md) · [การเปรียบเทียบโมเดลและข้อจำกัด](docs/model-comparison.md)

## โมเดลและระบบ

| เอเจนต์หรือระบบ | การรองรับปัจจุบัน |
| --- | --- |
| Gemma 4 12B IT, INT4 | โปรไฟล์ v2 ในเครื่องที่ทดสอบแล้ว |
| Gemma 4 E4B IT, INT4 | รันไทม์ในเครื่องรองรับ แต่ยังไม่มีการเปรียบเทียบ v2 ในเงื่อนไขเดียวกัน |
| OpenAI GPT-Live + เอเจนต์เบื้องหลังที่ระบุชื่อ | ต้องเพิ่มตัวเชื่อมต่อ |
| OpenAI Realtime | ต้องเพิ่มตัวเชื่อมต่อ |
| Gemini Live | ต้องเพิ่มตัวเชื่อมต่อ |
| ElevenLabs Agents | ต้องเพิ่มตัวเชื่อมต่อ |

ชุดระบบในเครื่องใช้ [speech-swift](https://github.com/soniqo/speech-swift): Whisper Large-v3 รุ่นเต็ม FP16, น้ำหนักหลัก VoxCPM2 FP16 / AudioVAE FP32, Silero VAD และ Gemma E4B สำหรับผู้โทร ตัวช่วยฟัง และผู้ประเมิน ระบบคลาวด์ยังไม่ได้เชื่อมต่อหรือทดสอบในเบนช์มาร์กนี้

## ตัวชี้วัดเปรียบเทียบ

| ตัวชี้วัด | สิ่งที่วัด |
| --- | --- |
| ความสำเร็จของงาน pass^1 | สถานะฐานข้อมูลสุดท้ายและการสื่อสารที่กำหนด |
| ความครอบคลุมและความล้มเหลว | จำนวนรอบที่ให้คะแนน/วางแผน การจบปกติ และข้อผิดพลาดอนุมานที่ไม่ให้คะแนน |
| ความหน่วง p50 / p95 | เวลาประมวลผล LLM และ ASR ของเอเจนต์ และเวลา TTS จนถึงเสียงแรก |
| ความหน่วงการตอบเสียง | จากจบคำพูดผู้โทรถึงเสียงแรกของเอเจนต์ ยังไม่มีสรุปมาตรฐาน |
| อัตราข้อผิดพลาดเครื่องมือ | การเรียกของเอเจนต์ที่ล้มเหลวหรือถูกปฏิเสธ / การเรียกที่พยายามทั้งหมด |
| เวลาทำงานสำเร็จ | เวลาโทรจำลองและเวลาจริงที่วัด แยกกัน |
| หน่วยความจำสูงสุด | หน่วยความจำจริงของโปรเซสเนทีฟ พร้อมระบุขอบเขตการวัด |
| ค่า API | USD ต่อรอบและต่อรอบที่สำเร็จ รวมรอบที่ล้มเหลว |

เปรียบเทียบด้วยงาน seed ขีดจำกัด สภาพเสียง และการตั้งค่าผู้โทร/ผู้ประเมินเดียวกัน คงชุดระบบเสียงไว้เมื่อเปรียบเทียบ LLM ในเครื่อง เอเจนต์เสียงเนทีฟและบริการจัดการต้องระบุระบบทั้งหมด เวลาของแต่ละส่วนเป็นคนละตัวชี้วัดกับความหน่วงการตอบเสียงตั้งแต่ต้นจนจบ

## ผลวินิจฉัยท้องถิ่นที่บันทึกไว้

| เอเจนต์ | ให้คะแนน / วางแผน | Pass^1 | ข้อผิดพลาดเครื่องมือ | LLM p50 / p95 | เสียงแรก TTS p50 / p95 | ค่า API / รอบ |
| --- | --- | --- | --- | --- | --- | --- |
| Gemma 4 12B IT, INT4 | 1/1 | 0/1 | 1/6 | 7.00 / 11.13 s | 1.22 / 1.70 s | $0 |

งานสายการบิน 12 หนึ่งรอบ seed 70 ใช้ v2 จำกัดไม่เกิน **600 วินาทีจำลอง / 1,200 วินาทีจริง** สายจบปกติหลัง **312.9 วินาทีจำลอง / 554.4 วินาทีจริงที่วัดได้** ฮาร์ดแวร์: Apple M5 Pro, 48 GB, เครื่องใช้ร่วมกัน นี่คือรอบพัฒนาหนึ่งรอบ ยังไม่มีการจัดอันดับหลายโมเดลในเงื่อนไขเดียวกัน [ข้อมูลและนิยามการวัด](docs/results/gemma4-12b-local-v2-airline.json).

## รันในเครื่อง

Python **3.12/3.13**, Apple Silicon, **macOS 15+** ทำตาม[การตั้งค่า](docs/runtime-setup.md)และ[การรัน v2](docs/local-v2.md)เพื่อเปิดบริการในเครื่อง ตรวจสอบผู้โทร/ผู้ประเมิน และรันงาน

```bash
uv sync --frozen --extra dev
uv run --frozen tau-voice verify
```

จำกัดการรันด้วย `--num-tasks`, `--trials`, `--max-seconds` และ `--wall-timeout` ตัวเชื่อมต่อคลาวด์และเพดานค่าใช้จ่าย USD **ยังไม่ได้พัฒนา** การอนุมานปัจจุบันทำในเครื่องและไม่ต้องใช้คีย์ API คลาวด์

การตรวจสอบ: `make test` · `make lint` · `make verify`.
